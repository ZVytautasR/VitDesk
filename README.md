# VitDesk

Программа для удаленного доступа.

## 📥 Как скачать и установить
1. Перейдите в раздел **Releases** (справа на этой странице).
2. Скачайте последнюю версию файла `VitDesk.exe`.
3. Запустите файл и следуйте инструкциям на экране.

## 🚀 Возможности
- Быстрое подключение
- Безопасная передача данных
